# LeetCode 75 & DSA Practice (Java)

This repository contains my solutions for the **LeetCode 75** study plan and various **Data Structures and Algorithms (DSA)** interview preparation problems implemented in Java.

## 📂 Project Structure

* **`src/DSA/`**: General Data Structures and Algorithms practice.
  * *Problems:* Two Sum, Move Zeroes, Maximum Subarray, etc.
* **`src/interview_75_DSA/`**: Organized LeetCode 75 problems broken down by topical weeks.
  * *Problems:* Merge Strings Alternately, Greatest Common Divisor of Strings, Kids With the Greatest Number of Candies, Can Place Flowers, etc.

## 💻 Environment & Tools
* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Build System:** Standard Java Project template

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Open the project folder using **IntelliJ IDEA**.
3. Navigate to `src/` to find and run individual problem files directly.
